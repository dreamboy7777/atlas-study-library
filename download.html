No computer? Use the web app

Host this folder on a local server or static host, open it in Safari, then choose Share → Add to Home Screen. That gives you an app icon without an IPA.

Which download should I use?

Windows: best for a laptop or desktop. It is a portable folder, so there is nothing to install and no admin rights needed.

Android: best for a phone or tablet. The APK is debug-signed and installs directly; it is not from the Play Store.

iPhone: the IPA needs a computer and a sideloading tool. If you want the quickest path, use the web app and add it to your Home Screen.

Your data stays yours

Atlas stores accounts, PDFs, chat, memes, and settings in the browser or app on your device. There is no cloud account and no Atlas server.

Export a JSON backup from the Admin console before uninstalling or switching devices.
