# Atlas for Android

A small WebView wrapper around `atlas.html`.

## Requirements

- JDK 17
- Android SDK 35
- Gradle 8.9 (or the Gradle wrapper generated by your IDE)

## Build locally

From this folder:

```bash
gradle assembleDebug
```

The APK is written to:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Build with GitHub Actions

Push a change under `mobile/` or `atlas.html` to `main`, or run **Build mobile apps** from the Actions tab. The workflow installs the Android SDK, builds the debug APK, and uploads it as an artifact.

## What the wrapper handles

- Full-screen WebView loading `file:///android_asset/atlas.html`
- DOM storage, IndexedDB, and local storage
- File picker for PDF uploads
- `window.AtlasNative.saveFile(name, mime, base64)` bridge for PDF, meme, and JSON downloads
- Back button navigation inside the app

## Notes

- The APK is debug-signed. It installs directly after enabling "Install unknown apps" for the browser or file manager.
- Data is local to the app. Uninstalling removes the app's library unless it was exported first.
- The APK does not include the `downloads/` folder from the repo; the download page is for desktop users.
